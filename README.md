# SADJIAH STREET RACER 2

Mobile racing game prototype.

Features:
- Player: WIZARD
- Automatic acceleration
- Brake and Nitro
- Choose One-Way or Two-Way road
- Choose Buttons, Steering Wheel, or Phone Tilt controls
- 101 levels
- Increasing speed and traffic difficulty
- Mobile and desktop controls

Upload `index.html` and `manifest.json` to a GitHub repository and enable GitHub Pages.
